  ## How delete works
  1. Program prints `Enter username to delete:` and reads the username.
  2. Validate in this order, stopping at the first failure:
     a. blank → `ERROR: Username cannot be blank.`
     b. not an existing user → `ERROR: Username not found.`
     c. is the logged-in user → `ERROR: You cannot delete the currently
  logged-in user.`
  3. If valid, print `User <username> deleted.` The user's games for sale
     are cancelled, and no further transactions are accepted on them this
     session.

  ## How buy works (only needed for delete_no_transactions)
  1. Program prints `Enter game name:` then `Enter seller username:`.
  2. The game and seller are checked BEFORE the buyer's balance, so the
     rejection here is because the seller was deleted, not insufficient
     credit.
  3. If the seller has been deleted this session, print
     `ERROR: Seller not found.`
  4. Rejected buys are not recorded (no 04 line).

  ## Input rules
